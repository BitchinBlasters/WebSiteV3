# _archive — retired pages kept for later

Nothing in here is published. The folder name starts with an underscore, which
GitHub Pages skips, so these pages are not reachable on bitchinblasters.com.au.

- `landing-page/index.html` — the original "coming soon" landing page with the
  early-bird sign-up (Formspree). Reuse it as a holding page if you ever need to
  take the site down for major work.
- `jefftron-sale/JefftronSale.html` — the Jefftron sale page that used to sit at
  /JefftronSale.

## Using the landing page as a holding page

1. Edit `_archive/landing-page/index.html` (contact details, message, dates).
2. Copy it to the repo root as `index.html`, replacing the live home page.
3. The rebuild ("Rebuild site from User Input") regenerates `index.html` from the
   site code, so switch the rebuild off or restore the original afterwards.
   Easiest: ask Claude to do the swap and the swap back.
