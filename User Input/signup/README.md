# /signup/ — news sign-up form settings

`signup-settings.txt` has one line:

    Endpoint: https://script.google.com/macros/s/XXXX/exec

Paste the form address here (a Formspree address like https://formspree.io/f/xxxx, or a Google Sheet script web app address), then run "Rebuild site from User Input".
While Endpoint is blank, the form falls back to opening the visitor's email app with their details filled in,
addressed to the business email, so sign-ups still reach you.
